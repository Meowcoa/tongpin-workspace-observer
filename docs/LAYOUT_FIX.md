# 同频 0.2.2：改动预览重叠修复

0.2.1 固定左栏后，主区是高度受限、可独立滚动的 flex 容器，但 workspace-body 仍使用 flex:1（0% basis 且可压缩）。长预览所在网格需要约 910 像素，父区却被压至 510 像素，下方客户端区提前开始，产生约 400 像素的重叠。长记录列表也会越过该父区。

修复让改动工作区使用 flex:1 0 auto，按实际内容高度参与主区布局，并让摘要和下方客户端区不被压缩。右侧主区继续独立滚动，左栏位置保持固定。没有用 z-index 盖住内容，也没有裁掉预览来隐藏问题。

布局回归必须覆盖“改动记录 → 文件预览 → 下方接入客户端”，不能只检查独立文件预览页。检查条件为工作区容纳左右两栏，客户端区顶部不早于两栏与预览元数据的底部。覆盖长 Markdown、长代码、表格、图片、PDF、长文件名和改动差异，并检查桌面及窄屏尺寸。

本版不改身份、消息、回合或文件监控协议。旧配置和已登记记录继续使用。更新时从托盘完整退出旧版，再运行新 EXE；无需重新创建接入身份。
